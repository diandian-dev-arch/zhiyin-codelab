# 知因 CodeLab 前端系统设计方案

## 项目概述
证据驱动的智能验收平台 - 教师定义检查要求，学生提交代码，Agent 生成反馈报告，教师复核发布

## 设计风格
**纸张折叠风格** - 专业、科技、高级、优雅
- 米白色纸质背景 (#fdfbf7)
- 对角线条纹纹理
- 立体折角效果
- 鼠标交互动效
- 卡片 3D 倾斜

---

**功能**:

### 3. 教师端主界面

#### 3.1 课程/任务管理 (Tasks Dashboard)
**路由**: `/teacher/tasks`
**对应现有**: `views/Tasks.vue` / `views/TaskV2.vue`
**功能**:
- 课程列表（卡片网格）
- 创建新课程/任务
- 任务配置：检查规则、要求定义
- 提交统计概览

**卡片信息**:
- 课程名称
- 提交数量 / 待复核数量
- 最近提交时间
- 快速操作按钮

#### 3.2 提交审核工作台 (Review Workspace)
**路由**: `/teacher/review/:submissionId`
**对应现有**: `views/Report.vue` / `views/ReportV2.vue`
**功能**:
- 左侧：证据面板
  - 构建日志
  - 浏览器截图
  - DOM 结构
  - 测试结果
- 中间：AI 候选反馈
  - 逐条审核
  - 编辑修改
  - 确认/拒绝
- 右侧：历史对比
  - 前次提交对比
  - 改进追踪

**交互**:
- 拖拽调整布局
- 折叠面板
- 证据图片点击放大
- 代码高亮

#### 3.3 学生管理 (Students)
**路由**: `/teacher/students`
**功能**:
- 学生列表
- 提交历史
- 成绩统计
- 导出报告

### 4. 学生端主界面

#### 4.1 我的课程 (My Courses)
**路由**: `/student/courses`
**功能**:
- 已加入课程列表
- 课程详情
- 任务要求查看

#### 4.2 提交作业 (Submit Work)
**路由**: `/student/submit/:taskId`
**对应现有**: `views/Task.vue`
**功能**:

- ZIP 上传（拖拽支持）
- 上传进度

**交互**:
- 拖拽上传区域
- 文件预览
- 上传状态动画

#### 4.3 反馈报告 (Feedback Report)
**路由**: `/student/report/:submissionId`
**对应现有**: `views/Report.vue`
**功能**:
- 查看教师发布的反馈
- 证据查看（截图、日志）
- 历史对比
- 下载报告

**展示方式**:
- 折叠卡片
- 彩色折角区分不同类型反馈
- 蓝色：功能问题
- 绿色：通过项
- 橙色：警告
- 粉色：建议

## 设计规范

### 色彩系统
```css
/* 主色调 */
--bg-primary: #fdfbf7;      /* 米白背景 */
--bg-secondary: #f9f5ed;    /* 次要背景 */
--bg-card: #fffcf5;         /* 卡片背景 */

/* 文字颜色 */
--text-primary: #1a1a1a;    /* 主文字 */
--text-secondary: #5a5a5a;  /* 次要文字 */
--text-tertiary: #6a6a6a;   /* 辅助文字 */

/* 强调色 */
--accent-gold: #daa520;     /* 金色强调 */
--accent-blue: #4682b4;     /* 蓝色（信息）*/
--accent-green: #4caf50;    /* 绿色（成功）*/
--accent-orange: #ff9800;   /* 橙色（警告）*/
--accent-pink: #e91e63;     /* 粉色（建议）*/

/* 折角颜色 */
--fold-default: #d4c5a0;    /* 默认折角 */
--fold-blue: #b8d9f0;       /* 蓝色折角 */
--fold-green: #c8e6c9;      /* 绿色折角 */
--fold-orange: #ffe0b2;     /* 橙色折角 */
--fold-pink: #f8bbd0;       /* 粉色折角 */
```

### 字体系统
```css
/* 标题字体 */
font-family: 'Noto Serif SC', serif;
font-weight: 700-900;

/* 正文字体 */
font-family: 'Inter', sans-serif;
font-weight: 400-600;

/* 代码字体 */
font-family: 'JetBrains Mono', monospace;
```

### 间距系统
```css
--spacing-xs: 8px;
--spacing-sm: 16px;
--spacing-md: 24px;
--spacing-lg: 32px;
--spacing-xl: 48px;
--spacing-2xl: 64px;
```

### 阴影系统
```css
/* 卡片阴影 */
box-shadow:
  0 2px 8px rgba(0,0,0,0.06),
  0 8px 24px rgba(0,0,0,0.08);

/* 悬停阴影 */
box-shadow:
  0 4px 16px rgba(0,0,0,0.1),
  0 16px 48px rgba(0,0,0,0.12);
```

## 响应式设计

### 断点
- 移动端: < 640px
- 平板: 640px - 968px
- 桌面: > 968px

### 适配策略
- 移动端：单列布局，折叠导航
- 平板：两列网格，侧边栏可收起
- 桌面：多列网格，完整侧边栏
