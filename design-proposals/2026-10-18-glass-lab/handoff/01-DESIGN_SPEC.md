# 01 · 设计规范 —— 知因 CodeLab「Glass Lab」视觉系统

> 这份规范是本次全站升级的**唯一视觉依据**。原型在 `prototype/`，生产级素材在 `assets/`，截图在 `screenshots/`。
> 规范与原型冲突时以规范为准；规范与**测试或无障碍约束**冲突时，以测试与无障碍为准（见 §8）。

---

## 0. 一句话定位

**夜色里的玻璃实验室**：深色、带色调的中性底，叠着半透明的毛玻璃层；四个明度对齐的莫兰迪色相按语义分工；液体水波与检查核心是品牌记忆点。动效偏慢、偏少、偏柔，优雅精致。

用户在设计评审中确认的偏好排序：**柔和玻璃 / 空间感** > 明亮活力 > 高级杂志感 > 精致科技感。

## 1. 设计评审中被否决的做法（不要重蹈覆辙）

| 被否决的做法 | 用户原话 / 原因 | 现在的做法 |
|---|---|---|
| 蓝紫霓虹渐变 | 「太具 AI 味」 | 任何地方不出现蓝紫渐变；冷色只用低饱和的雾青 / 雾蓝 |
| 三个高饱和强调色同时出现、跨色相渐变、大面积纯亮色块 | 「色彩搭配不够高级美观耐看，很奇怪」 | 四个色相**统一明度与饱和度**，按语义使用；渐变只在相邻色相之间 |
| 只用一个主色 | 「单色太单调了」 | 保留四色相，但每个都有明确角色（§2.2） |
| 背景用波点 | 「改成液体，更好展示光影细节、更具美感」 | WebGL 液体 + 真实水波（§6） |
| 液体只会流动、鼠标搅动漩涡、交互频繁、节奏快 | 「不够像液体，把水波纹做好，交互频次降低，动画慢一些，优雅精致一些」 | GPU 波动方程水波；落滴有距离 / 时间阈值；全站动效节奏放慢约 40% |

## 2. 色彩

### 2.1 四套配色（深色，`<html data-theme>` 切换，默认 `bronze`）

| id | 名称 | 底色 | c1 主色 | c2 绿 | c4 暖伴色 | c5 冷伴色 |
|---|---|---|---|---|---|---|
| `bronze` | 石墨·铜金 | `#0d0c0b` | 香槟铜 `205 165 120` | 鼠尾草 `146 178 142` | 陶土玫瑰 `212 144 126` | 雾青 `130 172 178` |
| `celadon` | 墨色·青瓷 | `#0a0f0f` | 青瓷 `143 188 170` | 沙金 `210 182 128` | 珊瑚 `214 150 130` | 雾蓝 `148 170 200` |
| `ochre` | 炭灰·赭石 | `#110e0c` | 赭石 `210 142 106` | 橄榄 `166 178 126` | 灰玫 `206 146 158` | 松石灰 `128 172 164` |

每套配色另有 `c3`：主色的浅调，用于高光与渐变的亮端。完整定义见 `assets/src/styles/glass/tokens.css`。

### 2.2 语义分工（必须遵守）

| 角色 | 令牌 | 用在哪里 |
|---|---|---|
| 主色 / 身份色 | `--gl-c1`，`--gl-role-rgb` | 主按钮、当前导航、焦点、关键数字。**学生身份**时 `--gl-role-rgb` 自动切到 c2（`body[data-role="student"]`） |
| 通过 / 成功 / 学生 | `--gl-c2`，`--gl-success` | 「通过」状态、已发布、学生头像与学生卡 |
| 需关注 / 警告 | `--gl-c4`，`--gl-warning` | 「需关注」状态、被反馈引用的源码行、复核阶段 |
| 信息 / 点缀 | `--gl-c5`，`--gl-info` | 执行中、信息提示、冷暖平衡的点缀、进度条起点 |
| 错误 / 破坏性 | `--gl-danger`（四套通用砖红 `222 128 112`） | 只用于错误与撤回、删除等操作 |

**流程五阶段的固定色相**（证据树、步骤条、时间线保持一致）：提交 c1 → 执行 c5 → 整理 c2 → 复核 c4 → 复提 c1。

### 2.3 用色规则

- 渐变只在**相邻色相**之间：`c3→c1→c4`（暖）、`c2→c5`（冷）、`c5→c1`（进度）。不做 c1→c5→c2→c4 那样的彩虹渐变（证据树树干是唯一例外，因为它对应五个阶段）。
- 同一屏里渐变文字最多 1～2 处。
- 大面积色块只用低透明度的色调（`rgb(var(--gl-c1-rgb) / 0.12～0.2)`），不用实色铺满卡片。
- `--gl-faint` 只能用于占位符和禁用态，**不得用于需要阅读的文字**。
- 对比度已验证：四套配色共 40 项全部达标（正文 ≥15:1，次级文字 ≥5.8:1，控件边框 ≥3.3:1）。修改任何颜色后运行 `node handoff/tools/contrast-check.mjs`。

## 3. 字体与排版

- **中文**：粗黑体系统栈（HarmonyOS Sans / MiSans / PingFang / 思源黑体 / 微软雅黑）。展示标题 900 字重、字距 -0.035em；页面标题 800；正文 400～500。
- **英文点缀**：衬线斜体（Iowan Old Style / Palatino / Georgia），用于副标题（如 *Evidence, not guesses.*）、强调词、大号数字。用 `.gl-serif`。
- **代码与元信息**：等宽（JetBrains Mono / Cascadia Code / Consolas），用于证据 ID、文件路径、眉题。眉题 `.gl-eyebrow`：12px、字距 0.14em、全大写，前面一条 22px 身份色短线。
- **不加载任何网络字体**（国内网络环境），全部使用系统字体兜底。
- 字号：工作台正文 14.5px，次级 13px，元信息 12px；页面标题 `clamp(28px, 3.2vw, 40px)`；首页展示标题 `clamp(46px, 6.4vw, 94px)`。数字使用 `font-variant-numeric: tabular-nums`（`.gl-num`）。

## 4. 材质与形状

- **玻璃**（`.gl-glass`）：半透明表面 + 160° 顶部高光渐变 + 1px 细线描边 + 内高光 + 深阴影 + `backdrop-filter: blur(20px) saturate(150%)`。强化版 `.gl-glass--strong` 用于对话框、登录卡等需要更高可读性的面板。
- **环境光**（`.gl-ambient`）：三团低透明度弥散光（c1 / c4 / c5），48～64 秒缓慢漂移，全站共享；工作台加 `.gl-ambient--calm` 降低存在感。叠一层极淡的胶片颗粒（`.gl-grain`）消除色带。
- **圆角**：输入框 14px，卡片与面板 20～28px，大型展示卡 40px，按钮与胶囊为全圆角。
- **光标光晕**：精确指针设备上，一个 520px 的柔光圆以 0.07 的缓动跟随光标。
- **降级**：`prefers-reduced-transparency` 时玻璃变为不透明表面；`prefers-contrast: more` 时加强线条和次级文字；`forced-colors` 时交给系统色（已写在 `components.css` 末尾）。

## 5. 动效

### 5.1 节奏原则：慢、少、柔

- 只动 `transform` / `opacity` / `filter`，不触发布局。
- 缓动：入场与位移用 `--gl-ease-out`（`cubic-bezier(0.16,1,0.3,1)`）；弹性只用于开关、勾选、分段滑块等小部件（`--gl-ease-spring`）。
- 时长：悬停颜色 0.2s；状态切换 0.4s；面板展开 0.7s；入场显现 1.1s；持续循环的装饰动画周期 ≥ 10s（卡片浮动 11s、Logo 旋转 18s、跑马灯 80s、光斑漂移 48～64s）。
- **工作台里的装饰性动画要克制**：不使用倾斜、磁吸、粒子、液体；保留入场显现（`.gl-reveal--soft`）、状态过渡、数字滚动、进度条、骨架屏、路由转场。

### 5.2 动效清单

| 动效 | 实现 | 用在 |
|---|---|---|
| 入场显现（上浮 + 去模糊） | `v-gl-reveal` + `.gl-reveal`；工作台用 `.gl-reveal--soft` | 全站分区、卡片 |
| 标题逐字上浮 | `v-gl-split` | 首页标题、登录标语 |
| 数字滚动 | `v-gl-count`（**值必须来自真实数据**） | 统计、评分 |
| 卡片聚光（不移动元素） | `v-gl-spotlight` + `.gl-card` | 全站卡片 |
| 3D 倾斜 / 磁吸按钮 | `v-gl-tilt` / `v-gl-magnetic` | **仅首页、登录页** |
| 配色切换圆形揭示 | `applyTheme(id, origin)`（View Transitions API） | 配色切换器 |
| 路由转场 / 列表增删 / 弹出 | `<Transition name="gl-page / gl-rise / gl-pop / gl-fade">`、`<TransitionGroup name="gl-list">` | 全站 |
| 液体水波 | `<GlLiquid>` | 首页首屏、登录页左侧 |
| 检查核心 + 代码粒子 | `<GlEvidenceCore>` | 首页首屏、登录页左侧 |
| 证据树生长 | `<GlEvidenceTree>` | 首页「工作方式」 |

### 5.3 减少动态效果

`prefers-reduced-motion: reduce` 时：所有过渡时长**精确为 `0s`**（测试断言 `transitionDuration === "0s"`），动画瞬时完成；液体只渲染一帧静态画面；粒子、水波、逐字动画、倾斜、磁吸全部关闭；入场元素直接可见。

## 6. 液体水波（品牌核心，修改前务必读完）

实现：`assets/src/glass/liquid.ts`（WebGL），组件 `<GlLiquid>`。

- **两层**：
  1. **水面**：GPU 波动方程，高度与速度存在半精度纹理里，两张纹理交替读写；
  2. **液层**：缓慢流动的缎面色场，采样时被水面法线折射，然后统一受光。
- **为什么像水**：
  - 水面单独计算法线：迎光坡面亮起细高光，背光坡面压暗，边缘有菲涅尔冷光；
  - 模拟里加了少量粘滞（`mix(s.g, n.g, 0.14)`），抹平网格高频，所以涟漪是圆润的同心波，而不是杂乱的条纹。
- **交互频次**：
  - 指针移动超过 110px 且距上一滴超过 0.32s，才落一滴；
  - 点击会荡开一圈大涟漪；
  - 空闲时每隔 3.2～6.7 秒自然落一滴；
  - 检查核心每次爆发，会从核心处推出一圈波。
- **调过的关键参数**（已经过多轮评审，不要随意改大）：

  | 参数 | 值 |
  |---|---|
  | 回复系数 | 1.15 |
  | 速度阻尼 | 0.996 |
  | 高度衰减 | 0.999 |
  | 水面法线系数 | 230 |
  | 折射系数 | 11 |
  | 液层流速 | `uTime * 0.028` |

  落滴半径（相对画布高度）与强度：

  | 落滴来源 | 半径 | 强度 |
  |---|---|---|
  | 点击 | 0.045 | 0.9 |
  | 指针 | 0.03 | 0.4 |
  | 自然落滴 | 0.026 | 0.5 |
- **性能**：
  - 渲染分辨率是 CSS 尺寸的 0.36～0.6 倍，按设备分级；持续掉帧会自动降档；
  - 水面网格约为 CSS 的 1/3，宽度上限 560 格；
  - 画布滚出视口、页面隐藏时暂停；
  - 同一时刻页面上最多一个实例。
- **降级**：
  - 无可渲染的半精度纹理时，只显示液层，没有水波；
  - 无 WebGL 时，显示 CSS 渐变；
  - 减少动态效果时，渲染一帧静态画面。
- **生命周期**：组件卸载时调用 `destroy()`，它会主动释放 WebGL 上下文。`anchor` 变化时只调用 `setAnchor()`，**不要重建实例**：释放过上下文的 canvas 无法再次初始化。

## 7. 页面与组件规格

### 7.1 首页（新增公开页，见实施计划 §4）

按滚动分段讲故事，每段各司其职：
1. **首屏**：左侧文案（眉题 → 逐字标题「让每一次提交 / 都有**证据**可循」→ 衬线副标题 → 说明 → 两个按钮 → 三个小指标）。右侧是检查核心，三张证据卡围绕它轻微浮动。背景是液体水波，左侧压暗保证文字可读。代码粒子经过正文区域时自动淡出。
2. **工作方式**：区块高 420vh，内容 sticky 固定；滚动驱动证据树生长，左侧五个步骤依次点亮，右下角显示生长进度百分比。
3. **证据报告**：源码、报告、复核结论三层玻璃面板悬浮在 3D 空间里；滚入时从倾斜状态摆正，之后跟随指针做视差。
4. **能力**：Bento 网格。主卡「发布权，永远在教师手里」占 2×2，下方「源码行并排引用」占满整行，各卡图标分色。
5. **数字**：四个统计数字，各带一个色相。
6. **师生**：教师卡偏暖，学生卡偏冷，背景各有一团缓慢形变的光斑。
7. **收尾**：描边大字跑马灯（悬停暂停）、行动卡片、页脚。

导航是顶部玻璃胶囊：向下滚动时隐藏、向上滚动时出现，底部有一条阅读进度线，当前分区高亮。首页的数字与能力描述**必须与产品事实一致**（以 README 为准），不得编造。

### 7.2 登录页

分屏布局：左侧 1.25fr，是液体水波、检查核心、三枚公转证据标签和身份标语；右侧 1fr，是玻璃登录卡。

身份分段控件只改变**外观与示意文案**：
- 主色在 c1 / c2 之间平滑过渡，同时影响液面和核心；
- 标语逐字重排；
- 核心爆发一次。

身份分段控件**不得**改变登录请求。

窄屏（≤900px）时场景在上（高 40vh），表单卡在下。

### 7.3 工作台

- **外壳**：`.gl-shell` 左侧玻璃侧栏（248px）+ 主区。导航项 `.gl-navlink`，当前项用身份色渐变底和左侧色条标识。
- **页头**：`.gl-pagehead`，由眉题、标题、说明和右侧操作组成。
- **容器**：面板 `.gl-panel.gl-glass`；可点击的条目用 `.gl-card`，配合 `v-gl-spotlight`。
- **其余组件**：状态、表格、列表、表单、标签页、对话框、Toast、空状态、代码引用、步骤条、统计，全部使用 `components.css`。效果见 `assets/gallery.html` 和 `screenshots/08-*`。
- 工作台不使用液体和粒子；背景只有 `.gl-ambient--calm` 和颗粒。

### 7.4 图标

继续使用 `lucide-vue-next`：统一 `stroke-width` 1.8，尺寸 16（行内）、18（导航 / 按钮）、22（卡片图标）。纯装饰图标加 `aria-hidden="true"`；只有图标的按钮必须有 `aria-label`。

## 8. 不可违反的约束（来自项目测试与 `apps/web/DESIGN.md`）

1. **点击区 ≥ 44px**：`.gl-btn` 各尺寸、分段控件、标签页都已满足；自定义控件同样要满足。
2. **焦点可见**：聚焦时 `outline` 不能是 `none`（测试断言密码框聚焦时 `outlineStyle !== "none"`）。
3. **悬停不移动可点击目标**：工作台内禁用 `v-gl-tilt`、`v-gl-magnetic`、悬停位移；按下时可以有轻微缩放。
4. **减少动态效果时过渡时长为 `0s`**。
5. **任何宽度不出现横向滚动**（测试检查 `scrollWidth <= innerWidth`，宽度 320 / 375 / 390 / 414 / 768 / 1280 / 1440）。
6. **对比度**：文字 ≥ 4.5:1，控件边框与非文字元素 ≥ 3:1。
7. **不编造数据**：工作台里的环形进度、数字、进度条只展示 API 返回的值。
8. **不改动可访问名称与中文文案**：测试大量使用 `getByRole` / `getByLabel` / `getByText` 定位元素，按钮名、标题、标签文字是承重结构。
9. **保留测试依赖的类名与 DOM 结构**：完整清单见 `03-ACCEPTANCE.md` §3。
