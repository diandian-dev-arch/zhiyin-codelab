How it works

一次提交，
长成一棵证据树

  1. 01

    提交 Submit

    学生上传 ZIP，或从片段、文件夹、Gitee、GitHub 固定一次成果快照。提交即留档，不依赖模型。

  2. 02

    执行 Execute

    Docker 隔离环境里构建、启动、驱动真实浏览器，八个独立案例逐一留下截图与日志。

  3. 03

    整理 Agent

    受限 Agent 只用六种工具阅读证据，把发现整理成能定位到源码行的反馈候选。

  4. 04

    复核 Review

    教师逐条采用、修改或驳回。模型只给候选，发布权始终在教师手里。

  5. 05

    复提 Compare

    学生按反馈修改后再次提交，两次证据并排比较，每一处进步都看得见。
