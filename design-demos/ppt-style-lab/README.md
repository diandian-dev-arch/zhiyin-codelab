# 知因 CodeLab · PPT 视觉方向室

## A 动态精修版

用户已选 A。打开 `a-refined/index.html` 查看第二轮封面与内容页。支持三种蓝色调、入场动效播放/暂停/重播/拖动、步骤聚焦、截图放大和全屏。左右键翻页，空格播放/暂停，R 重播。所有素材本地加载，整个文件夹可离线复制。

动效只在进入页面时播放一次，系统启用减少动态效果时默认静态。原始三方向样张继续保留，精修版不替换正式 PPTX。

双击 `index.html` 打开选择页；整个 `ppt-style-lab` 文件夹可独立复制、离线使用。无模型调用，无外部字体或CDN请求。

- A：明亮产品发布，封面与证据链内容页。
- B：深色调查图谱，封面与证据链内容页。
- C：人文编辑设计，封面与证据链内容页。
- `deck.html`：六页统一概览与演示，支持方向键、Esc回到概览。
- `slides/`：1920×1080独立样张。
- `previews/`：实际浏览器渲染截图。

本轮是风格选择，尚未选定正式方向，也没有替换原PPT。页面「记下这个方向」只保存本机偏好，不会自动给聊天发送消息。
