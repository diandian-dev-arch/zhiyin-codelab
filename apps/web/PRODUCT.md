# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Teachers define practical tasks and review evidence before publishing feedback.
Students submit fixed project versions, read published feedback and revise.
Both roles can read their own project source with a personal model account.

## Product Purpose

Zhiyin CodeLab connects requirements, execution evidence and teacher decisions.
AI feedback is a candidate, never an automatically published judgment.

## Capabilities and Constraints

Vue 3 and Vite; production entry is src/main-codelab.ts. Preserve all API,
authentication, permission, business state and test contracts. The Glass Lab
upgrade adds only the public /welcome route and local appearance preferences.
No new dependency, external font or invented operational metric is allowed.

## Evidence on Hand

README.md in the repository root describes eight independent checking cases,
five core requirements and six restricted Agent tools. These are product
capabilities, not proof of real-model quality or classroom acceptance.
The user-approved Glass Lab handoff contains source assets and visual references.

## Accessibility & Inclusion

Targets at least 44 by 44 pixels; visible keyboard outlines; no horizontal
overflow at 320 through 1440 pixels; reduced motion uses exactly zero-second
transitions. Preserve native forms, disclosures, selects and source-reader focus.
Text contrast is at least 4.5:1, functional boundaries at least 3:1.
