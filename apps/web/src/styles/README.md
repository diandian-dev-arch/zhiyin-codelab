# 工作台样式责任

当前视觉：Glass Lab。源入口为 `apps/web/src/main-codelab.ts`。本文件说明实际兼容边界，不新增另一套主题，不代表所有界面状态已经视觉验收。

## 责任与加载顺序

| 层 | 文件 | 责任 |
| --- | --- | --- |
| 历史功能基底 | `../style.css`、`studio.css`、`motion.css`、`manuscript.css`、`coursework.css` | 旧路由、结构、功能类和历史控件；视觉已由 Glass 层接管的部分不能再作为新规范复制 |
| 视觉事实 | `glass/tokens.css` | 四主题颜色、材质、尺寸、动态和语义令牌；新颜色优先在此找已有角色 |
| 令牌桥 | `../../tokens.css` | 将既有功能令牌映射到当前主题，不创建第二套色板 |
| 当前基础 | `glass/base.css`、`glass/motion.css` | 文本、页面、原生控件基础和当前动效/减少动态 |
| 当前组件 | `glass/components.css` | 可重复 Glass 组件；不将某一业务页的例外塞进所有组件规则 |
| 历史适配 | `glass/legacy-skin.css` | 保留功能 DOM 的历史页面适配，包含共享外壳尺寸；不是任意新增覆盖的入口 |
| 课程领域 | `glass/coursework.css` | 任务化课程的表单、列表、来源与版本展示 |
| 共享搜索 | `glass/search.css` | 搜索框唯一共享外观，页面不再重复画边框与清除动作 |
| 共享收尾 | `glass/workspace-finish.css` | 外壳、页头、原生状态和已验证共享细节；不追加无关业务页面补丁 |
| 局部业务 | Vue 组件的 scoped style | 仅属于该组件的布局、阅读窗、反馈与状态，优先就地维护 |

实际 import 顺序以 `main-codelab.ts` 为准。不要通过再次引入另一份 reset、重写所有 button 或增加更高优先级的全局层来解决局部问题。

## 改动规则

1. 先确认正式路由和元素归属，再看 computed style 的最终来源；旧原型和未挂载页不是当前外观依据。
2. 修改主责层，避免同一属性在多个新文件反复覆盖。迁移一个规则时先核对所有使用者和窄屏/主题/状态，再移除已证明冗余的旧规则。
3. 不为清理目录批量删除历史 CSS。新旧路由、源码阅读器、教师未保存草稿与可访问名称可能依赖旧类。
4. 不为降行数制造一次性组件；只有取消、来源准备、报告阅读等明确责任确实能独立验证时才抽出。
5. 新增局部规则写明作用范围；没有用户要求不重做登录、欢迎页、配色或字体。共享控件使用已有令牌和图标。
6. 同批复核普通/禁用/忙碌/错误/空态、键盘焦点、减少动态、长文本与窄窗口；必要说明和来源限制不能为了首屏指标删除。
