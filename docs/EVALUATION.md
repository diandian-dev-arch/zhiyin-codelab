### 四组对照

| 组 | 输入与操作 | 统一终点 |
| --- | --- | --- |
| H 人工 | 相同项目与要求，正常开发工具、合理缓存；不提供其他组报告 | 教师独立形成可发布反馈 |
| R 结构化报告 | 固定八案例和原始证据，无模型 | 教师阅读、修正、确认并发布 |
| S 一次性总结 | 与 A 相同封存基础证据，一次模型总结、无补查 | 教师判断候选、修正并发布 |
| A 受限 Agent | 与 S 相同基础证据，有界六工具和固定探查 | 教师判断候选及新增证据、修正并发布 |

不能以候选生成完成作为计时终点。当前课程页面默认「仅基础检查」；参与者明确选择「AI总结」或「Agent分析」后，下一次检查才使用该账号的模型，模式和个人配置身份在入队时冻结。`CODELAB_INITIAL_ANALYSIS_MODE` 属于历史/诊断配置，不能替代生产页面的个人计费选择。详见 [配置说明](MODEL_SETUP.md)。正式对照须核对同一封存输入与实际请求记录，不能将 A 首轮临时改称 S，也不能默认两个重新执行的 Run 使用相同证据。按教师与样本家族交叉/平衡安排顺序，记录既往接触，尽量隐藏报告来源；无法盲评时注明。预先登记实际可用的模型参数与重复次数；个人窗口未提供的温度控制不能写成已固定，服务端默认未知时明确记录。失败、未探查及不值得探查也计入分母，不挑最好一次。

### 原始记录与判定

每次保存 experimentId、分组、样本/家族/分区、教师代号、配置/模型版本、输入哈希、Run/AnalysisAttempt、开始结束时间、证据清单、原候选、教师修订、发布身份、失败分类。耗时分开记录配置摊销、执行等待、实际阅读、修改和发布；人工组也计入准备与合理缓存。

逐项登记误报/漏报/未执行、事实错误、无依据归因、错误引用、建议可执行性、教师修订量和下一批使用意愿。构建失败/准备受阻不可简单算功能失败；人工更正不修改基础事实。模型费用保存真实调用、token、计价版本及补查耗时，缺少用量填 unknown，不能填 0。截图只有索引时明确 pixelsRead=false；源码定位仅作为原因假设。

真实教师需确认课程、班级、原工作流、五项自动要求、人工项、公开 data-testid 约定与禁止新依赖的限制；登记授权范围、保留期限、删除方式和可展示范围。逐案例真值由独立评阅者登记操作、判定、证据、禁止归因、理由和争议裁定，不能由开发者冒充教师确认。G4 未通过前只运行已授权团队样本。

`eval/promptfooconfig.yaml` 仍只是历史单条反馈结构/引用夹具，未运行真实 provider，不代表四组或 Agent 质量评测。当前不计算节时百分比或通用准确率。Agent 若增加复核负担，应保留 R 并记录负结果，不改冻结真值追求效果。

## Promptfoo 的接入范围

`eval/promptfooconfig.yaml` 提供结构和证据归属回归的起点。首次真实模型评价需安装团队审核的固定 Promptfoo 版本，设置评测专用 provider，运行后登记版本与报告哈希。该配置未在本机调用真实模型，也不代表完整质量评测。

继续投入条件：教师确认下一批可用、正确/缺陷版本可重复验收、包含全部成本后仍有收益。若 Agent 增加复核负担，保留确定性检查与证据整理，缩减自动归因。
