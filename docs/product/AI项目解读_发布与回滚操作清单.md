# AI 项目解读发布与回滚操作清单

日期：2026-10-14。本文是操作与验收清单，不是已发布证明。

## 发布前

- 核对目标网页端口、API 代理目标、数据库路径与构建版本，记录健康接口及鉴权后项目读取结果。不要根据端口监听推断系统可用。
- 检查是否存在运行中的付费分析；未经协调不要中断或重启。不同端口可能属于不同实例，不能批量关闭进程。
- 保存数据库备份及当前可回退构建，验证恢复方法；不要将密钥、源码正文或账户令牌写入检查记录。
- 执行类型检查、相关后端回归及真实点击浏览器回归；mock 验证与真实模型质量验收分开记录。

## 独立开关

| 开关 | 生效位置 | 行为 | 应用方法 |
| --- | --- | --- | --- |
| `SOURCE_EVIDENCE_FLOWS=1` | API 分析进程 | 请求可选结构化链路并校验；其他值默认关闭 | 在目标运行环境配置，确认无付费任务后按现有部署流程重启 |
| `VITE_EVIDENCE_FLOWS=0` | 前端构建 | 隐藏结构化链路，保留场景说明与源码引用 | 必须重新构建并部署；只修改运行时环境不会改变旧静态文件 |

两个开关相互独立。关闭生成不会清除已有报告的链路字段；关闭展示不会停止后台生成。完全停用新能力时应同时关闭两端，且不得自动重跑历史报告。

## 离线回滚回归（PowerShell）

以下预览使用独立输出目录及端口，不替换当前网页。每段中的环境变量仅用于所在终端；完成后恢复原环境值。预览端口被占用时换空闲端口，不终止未知服务。

```powershell
$env:VITE_EVIDENCE_FLOWS='0'
pnpm --filter @codelab/web exec vite build --outDir ../../output/evidence-flows-off-preview
pnpm --filter @codelab/web exec vite preview --host 127.0.0.1 --port 5197 --strictPort --outDir ../../output/evidence-flows-off-preview
```

在另一个终端从仓库根执行：

```powershell
$env:READER_TEST_ORIGIN='http://127.0.0.1:5197'
$env:READER_EXPECT_FLOWS='0'
node scripts/verify-project-reader.mjs
```

测试拦截所有 API，只允许 GET，不上传、不修改用户数据、不调用模型。完成后仅停止本次启动的预览进程。

## 回滚后必须检查

- 有效新链路不显示，原场景、全部引用仍可访问。
- 旧报告、缺失可选字段、损坏字段不会阻塞阅读。
- 最新任务失败后可打开历史报告；阅读历史时仍能看到另一个任务进度。
- 1440×900、768×1024、390×844、320×740 无页面横向溢出；源码关闭后焦点恢复。
- 同版源码、账户权限、预算确认和付费防重不因关闭视图而改变。
- 不删除报告，不重置数据库，不自动重算，不将“视图关闭”误报为“分析任务已停止”。

## 本轮证据与未完成项

关闭展示开关的独立生产构建成功，上述阅读脚本通过四尺寸、关闭视图、源码联动、历史和空报告检查。构建主包约 522 KB，存在超过 500 KB 的警告，仍需性能评估。

后续按需加载改造的默认生产构建：主包 462.52 KB，项目块 68.92 KB，已无 500 KB 警告；该结果不替代上面关闭开关构建的记录。独立预览上已验证项目块失败恢复、阅读与配置四尺寸交互，仍未开展低端设备、慢网络下的体验性能测量。进入项目时需要加载两个块，不将分包宣称为总资源减少。

这不证明正式部署完成：真实实例鉴权、数据库备份恢复、在运行任务安全边界下部署、真实模型费用与语义质量、师生试测和人工视觉签收仍需独立验收。生成开关已有离线分析入口回归，不代表真实模型新增字段的成本没有变化。

## 2026-10-17 阅读 V2 增量

新增独立开关：`SOURCE_READING_BRIEF=1` 才为新报告生成可选阅读层，默认关闭；`VITE_READING_BRIEF=0` 隐藏阅读摘要和条件/验证/修复指导，需重新构建。它们与现有 evidenceFlows 开关彼此独立。完整实施、自动回归、原实例限制及未完成门禁见 [V2实施与验收记录](AI项目解读_V2实施与验收记录.md)。

展示回退演练命令（独立输出和端口；端口占用则换端口，不停止未知服务）：

```powershell
$env:VITE_READING_BRIEF='0'
pnpm --filter @codelab/web exec vite build --outDir ../../output/reader-v2/build-rollback
pnpm --filter @codelab/web exec vite preview --host 127.0.0.1 --port 5177 --strictPort --outDir ../../output/reader-v2/build-rollback
```

另一个终端执行：

```powershell
$env:READER_TEST_ORIGIN='http://127.0.0.1:5177'
$env:READER_EXPECT_BRIEF='0'
node scripts/verify-reader-v2.mjs
```

脚本拦截所有 API；默认阅读、配置开关、历史切换、源码读取均不能发起分析。回退不会删除或修改已存报告；原报告仍可展开。生成开关的回归命令为 `pnpm exec vitest run tests/source-reading-brief.test.ts`，使用离线替身，不产生真实费用。人工语义、费用对比和正式部署保持未验收。
