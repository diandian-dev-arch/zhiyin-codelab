# 个人模型配置与费用归属

学生、教师登录自己的账号后，在项目分析页面点击“模型设置”，打开“个人模型设置”窗口。未配置的账号可点击“配置我的模型”。任务页和报告页也提供入口。

## 使用步骤

1. 选择 DeepSeek、OpenAI 或通义千问。
2. 填写该服务商可用的模型名称和自己的 API Key。窗口提供获取密钥的官方入口。
3. 点击“保存配置”。保存不发起模型调用，也不代表已经验证模型可用。
4. 按需点击“测试连接”。这会发送短提示并产生少量 API 费用，不发送项目源码；连接通过不代表完整项目分析质量已经通过验收。
5. 返回项目页面发起分析。费用由模型服务商向所用 Key 的账户收取。

## 费用与数据边界

- 配置按登录账号隔离，教师和学生不会自动共用密钥。实际付款账户是 API Key 所属服务商账户。
- 未配置时不提供新的 AI 项目分析，不自动回退到平台共享密钥；已有报告仍可查看。
- 服务端加密保存密钥，读取配置不返回密钥原文。可替换或移除密钥。
- 正在排队或执行分析时禁止修改配置，任务绑定发起时的配置版本，避免静默切换计费账户。
- 项目分析会向所选服务商发送筛选后的源码片段，课程分析还可能发送检查结果与证据文字。
- 高级设置中的单次最大输出不是整项分析的费用上限。需要硬性消费限额时，应在服务商账户设置预算；应用目前不承诺人民币总额封顶。
- 平台仍承担自身服务器、存储、项目执行环境等费用。个人模型配置只转移模型 API 调用费用。
