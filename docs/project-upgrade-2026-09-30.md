# 项目升级交付记录 · 2026-09-30

本次直接升级现有应用的 AI 项目分析、实训任务与师生评价流程。项目可以独立保存和分析，也可以作为实训作品提交，让任务要求、代码理解、同伴建议、教师反馈与优秀作品学习围绕同一份提交展开。

## 实际变化

| 功能 | 现在的使用方式 |
| --- | --- |
| 独立项目入口 | 从「AI 项目分析」导入普通项目，无需先创建课程或选择技术栈。支持 ZIP；文件夹在浏览器本地打包后上传。 |
| 保存与分析分开 | 选择文件后可直接「保存项目」，不需要 AI 密钥，也不会自动调用模型；选择分析时再确认模型、范围与预算。 |
| 多语言与任务方式 | 开放项目接收常见语言的 UTF-8 源码。教师默认发布开放项目任务，也可选择已有的固定模板验收方式。 |
| 报告阅读 | 报告分为「项目概览」「模块与链路」「问题与证据」「学习路线」四个页签。点击代码引用可打开相应源码与行号；过程、费用与高级设置收进分析详情。 |
| 课程闭环 | 教师发布要求、截止时间及评价参考；学生上传或关联已有项目；同班学生填写优点、改进建议并推荐作品；教师发布反馈、确认完成情况和优秀作品。 |
| 源码与报告版本 | 每次课程提交绑定具体项目版本，改进后上传形成后续提交。重复提交同一项目返回原记录。新生成的课程导读先供教师或作者预览，显式采用后再向同班师生更新。 |
| 费用与复用 | 生成导读使用实际发起人的个人模型账户；教师分析学生作品使用教师自己的账户。符合源码、范围、模型配置及计费归属等条件的成功报告可复用，避免重复模型调用。 |

## 权限与边界

- 学生在提交时授权本班师生读取这份作品的源码与导读；优秀作品展示另行勾选同意。当前没有独立的提交后展示授权修改入口。
- 课程访问只覆盖具体共享提交，不开放作者的个人项目历史。教师正式反馈对教师与作者可见；同班学生可阅读同伴评价及入选理由。作者不能给自己互评。
- 选优由教师确认，需要作者授权、达到任务目标及具体入选理由；优秀作品范围为当前班级的当前任务，并以学生最新提交为准。同伴推荐作为教师判断的参考。
- 只有本次分析的实际付费发起人可以停止分析。停止会保留作品和现有报告，已发生的调用费用仍按模型服务商规则结算。
- AI 导读属于静态源码分析，不证明项目已运行、测试已通过或结论完全正确。教师和学生仍需结合源码与实际运行进行核对。
- 当前使用个人模型付费模式，没有学校共享额度。开放项目导入不提供任意课程模板的运行验收；固定模板仍使用原有受限检查链路。
- 尚未开展真实付费模型的报告质量对照测试，也未测得实际省钱幅度。现阶段只能确认保存、共享阅读与满足条件的报告复用不会新增模型调用。
