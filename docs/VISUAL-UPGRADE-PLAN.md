# 视觉升级计划

## 目标
基于 `design-proposals/variant-paper-fold.html` 的纸张折叠美学，为现有业务页面升级视觉设计，**不改变任何功能逻辑**。

## 原则
1. ✅ **保留所有业务逻辑**：API 调用、状态管理、路由、表单验证、错误处理
2. ✅ **只修改视觉层**：CSS 样式、布局、动画效果
3. ✅ **保持功能完整**：真实的上传、分析、报告、个人模型配置
4. ✅ **渐进式升级**：逐个页面升级，确保每个页面都能正常工作

## 纸张折叠美学核心元素

### 1. 背景系统
- 纸质纹理背景（对角线条纹 + 细密网格）
- 鼠标跟随光晕效果
- 温暖的米黄色调 (#fdfbf7, #fffcf5)

### 2. 卡片样式
- 折角效果（右上角三角形折叠）
- 不同颜色折角：蓝色、绿色、橙色、粉色
- 悬停时折角扩大、卡片轻微旋转和上浮
- 柔和阴影和立体感

### 3. 字体排版
- 标题：Noto Serif SC（衬线，书法感）
- 正文：Inter（无衬线，现代感）
- 代码：JetBrains Mono

### 4. 动画效果
- 淡入上浮动画
- 卡片悬停 3D 倾斜
- 平滑过渡效果
