# 个人项目分析模型设置

任务：学生、教师用自己的服务商账户进行源码分析。平台不为缺少个人配置的账号垫付模型调用。历史报告继续可读。2026-09-29追加课程总结与Agent个人计费，规则见下方；早期仅覆盖普通ZIP的实现范围保留在当日验收记录。

窗口采用双栏：主栏填写，窄栏是账户与费用说明。相比全屏设置页，窗口保留当前项目上下文；相比多步向导，用户可以一次完成三项必要输入。

```text
个人模型设置                         关闭
当前账号 / 已配置状态
服务商选择      | 本次由谁付费
模型名称        | API Key 所属账户
API Key         | 发送哪些内容
高级设置        | 源码片段与分析提示
测试结果 / 错误  | 获取密钥
移除密钥          测试连接  保存配置
```

颜色：墨蓝 #22374a，青绿 #147d83，雾白 #f3f5f4，纸白 #ffffff，边线 #dbe3ea，提醒赭金 #986326。标题用系统中文黑体粗字重，正文用系统无衬线，模型名和 endpoint 用等宽字体。24/16/12px 字号与24/16/8px间距。费用栏用竖直青绿线和账户标记，形成可核实的计费归属；不加模型智能分数、装饰数字或假进度。

设计复查：删除普通设置弹窗常见的营销说明和大图标。关键区别是费用归属、密钥不可回读、测试可能收费、保存不代表验证通过。窄屏单栏；原生 dialog 提供焦点围栏、Esc关闭和返回焦点；操作中阻止关闭以避免结果状态丢失。

实现边界：预设官方 DeepSeek / OpenAI / 通义千问端点，支持自填模型名；不接受任意代理 URL。AES-256-GCM 存储密钥，账号ID绑定认证；每次任务保存配置版本，每次调用前校验。测试只发送固定短提示，不发送项目源码，不自动重试。配置窗口不显示服务商余额，最终账单以服务商为准。

## OpenAI 预设升级（2026-10-17）

按用户指定，将 OpenAI 快捷模型更新为 `gpt-6.1-sol`、`gpt-6-astra`，切换到 OpenAI 服务商时默认选前者。共享预设不再推荐 GPT-4.1；已保存的旧模型、自定义模型、密钥和历史报告不会自动迁移，只有用户明确保存才改变个人配置。

OpenAI Docs 核对来源：[GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)、[GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)、[迁移指南](https://developers.openai.com/api/docs/guides/latest-model/gpt-6-astra.md#migration-quickstart)。两者支持无工具的 Chat Completions，因此保留现有 JSON 文本链路；未引入 Responses、工具或新推理等级。两模型使用 `max_completion_tokens` 限制包括推理的输出预算，不发送第三方 `enable_thinking`/`thinking` 参数。显式配置不支持的 temperature 在发请求前报错，不悄悄改写采样策略；其他模型的请求格式保持不变。

这两个模型的连接测试使用 1,024 tokens 上限（包含推理），避免原 64 tokens 在输出 JSON 前耗尽；其他模型仍为 64。测试仍可能收费、仅一次、不发送项目源码，保存配置不触发测试。本轮仅以本地模拟服务验证参数、用量、旧配置兼容与账单边界，未确认用户账户的实际模型权限，也未发起付费调用。高级上下文/输出预算和已冻结的任务配置不变。

## 课程分析的个人计费（2026-09-29）

学生和教师都可创建基础检查；默认不调用模型。检查记录上方的选择框可为下一次检查选择「AI总结」或「Agent分析」，创建成功后重置为「仅基础检查」。计费人始终是点击创建检查的已登录账号，不根据提交归属借用学生或教师密钥。教师报告页的重新分析同样使用发起教师的个人配置；教师没有密钥时基础报告仍可复核发布。

沿用窗口的墨蓝、青绿、雾白色；课程选择区只用青绿左边线标出费用边界，主体保持现有中文字体，模型标识沿用等宽字。比较过独立设置页与就地选择，采用后者，避免离开当前提交。唯一新增布局是「分析方式 + 当前模型 + 谁付费」的紧邻关系，窄屏纵向排列。没有新增营销头图、假预算金额或装饰动画。

入队事务使用与个人配置编辑相同的锁，冻结发起者ID、非敏感模型配置及credentialRevision。个人设置在源码分析、课程AI排队/执行期间不能修改；worker每次模型请求重新核对版本、限制输出并检查上下文预算。生产API、桌面工作台和独立v2 worker都启用个人解析器，无环境共享密钥回退。仅测试库/显式诊断程序仍可注入固定provider；生产中已排队但没有个人计费快照的历史任务不会自动借用任何密钥，保留基础报告并要求明确重新发起AI。
