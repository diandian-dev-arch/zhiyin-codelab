# 当前新前端业务接入清单

核对日期：2026-09-29。用于把新视觉接回现有真实业务；不是已完成声明。当前入口main-codelab.ts，旧业务入口main.ts仍保留。本轮没有覆盖新前端文件。

## 当前阻断

1. Login.vue不请求服务器，只按选择角色导航。客户端角色选择不能授予教师权限。
2. student/Submit.vue不上传文件，却提示“作业提交成功”；saveDraft也只打印日志并提示成功。
3. Settings.vue不持久化设置，却提示“设置已保存”。默认用户/邮箱不来自会话。
4. 新路由缺少/projects、/projects/:id、/tasks/:id、/runs/:id、/publications/:publicationId。直接访问历史报告无法保持原业务含义。
5. 学生/教师列表为内置数据；不能作为当前班级、提交数量或评测结果。

## 接入契约与现有实现

| 用户功能 | 应复用的现有实现 | 必须保留的行为 |
| --- | --- | --- |
| 登录/退出/会话恢复 | api.ts的useSession、login/load/logout及App.vue错误状态 | 服务器验证身份，登录后加载真实role和businessVersion；15秒等待边界；清空密码；退出前保护未保存草稿 |
| 教师任务与学生课程 | views/Tasks.vue，/api/v2/tasks、/api/v1/classes | 列表来自服务器；分页、空态、错误/重试；教师创建班级和学生管理不可丢失 |
| 任务/规则/课程提交 | views/TaskV2.vue，/api/v2/tasks/:id及submissions | 固定规则版本；保存提交与执行检查分开；请求身份与不确定结果恢复；后端校验归属 |
| 普通项目ZIP分析 | views/Projects.vue，/api/v2/projects及详情 | 不要求课程模板；个人模型；100MiB上传边界；导入范围与跳过项；真实阶段状态和历史 |
| 个人模型配置 | components/PersonalModelDialog.vue，/api/v2/model-settings | 密钥不回显；服务商/模型/上下文预设；连接测试收费说明；不使用平台兜底 |
| 运行/教师复核 | views/ReportV2.vue，/runs/:id | 基础结果和人工判断分开；证据查看；草稿恢复；保存、内容哈希确认、版本发布；失败保留草稿 |
| 学生公开报告 | views/ReportV2.vue，/publications/:publicationId | 仅本人公开快照和白名单证据；刷新/历史链接可访问；不能显示教师私有草稿 |
| 复提与比较 | TaskV2/ReportV2现有逻辑 | 同条件才标记修复/回归；规则变化标不兼容；旧发布保持可读 |
| 通知、个人资料、主题 | 新页面尚无已核对的持久实现 | 没有服务支持前不得展示“已保存/已发送”等成功反馈，不拿占位数据冒充当前用户事实 |

原普通项目AI分析和受控课程执行是两个入口，不能把多文件作业上传替代ZIP项目分析。不得为新UI降低鉴权、绕过CSRF、由客户端指定身份或把模型候选自动发布。

## 交接顺序

1. 确认新前端是否还在其他工具中编辑、确定接线文件归属；避免两处同时改入口和路由。

4. 接教师复核、学生发布快照和比较；复用既有幂等、确认、草稿恢复逻辑。

- 从页面入口实际完成普通ZIP→个人模型→分析状态→报告/源码引用→重新打开历史。不新增付费测试调用前，先用隔离合成模型验证链路；真实质量另行登记。
- 从教师创建/发布任务到学生提交、真实检查、教师编辑确认发布、学生阅读和复提比较均可到达。
- 保存失败不弹成功；请求已提交但回执丢失可恢复，不能自动重复付费分析或重复发布。
- 旧URL、桌面和移动布局、键盘焦点、减少动态效果、错误和空态均实测。
