# Agent 调查工作台：核心体验设计

2026-09-28，根据用户新要求调整产品主次：Agent调查成为教师报告页的首要入口，基础检查成为可靠材料底座，教师复核是结果落地环节。替代此前把AI放在折叠工具栏中的布局。

## 核心任务与信息顺序

教师要回答：哪里值得关注、Agent实际查了什么、哪些解释有证据、怎样指导学生修复。页面先展示调查目标与行动入口，再展示实时调查轨迹，完成后在同一区域展示结构化发现；底部保留逐项证据与教师编辑/确认/发布。学生仍只读已发布快照。

1. 分析前：从真实基础结果生成待关注条目，允许直接跳到证据；主动作“开始Agent调查”，总结/实验配对移到分析设置。
2. 分析中：显示当前模型/工具动作、完成操作数、已归档补充材料次数、真实耗时。使用非百分比的证据轨迹与细线环形动效；节点只根据服务器事件改变，动效表示活动而非预计完成度。
3. 分析后：明确所属分析记录；依条目展示观察、可能原因/支持程度、修复建议与证据入口，可逐条采用到教师草稿。切换历史记录可以比较已有候选，最新失败不能被旧成功伪装覆盖。
4. 失败/取消：保留已经完成的调用与补充材料标识，解释无候选状态；允许新调查，基础材料继续可复核。

## 实现边界

复用真实analysis_attempts/analysis_operations和现有六工具，保持服务端预算、取消、幂等、教师CAS与候选采纳协议。展示操作摘要而非模型内部思维链。不宣称任意自由探查或自动修复已实现。没有Token流数据时不展示伪造的逐字输出，也不以等待时长计算百分比。

进度由教师鉴权review接口返回的operations驱动，轮询不覆盖未保存教师修改；读取失败必须提示连接状态，停止活动动效并保留最后已知记录。结果证据与当前候选一致；查阅补充材料不自动选入公开报告。采纳后仍需教师确认。

## 视觉与响应

延续杏光Studio的暖纸面、杏色重点，调查区域采用墨紫色细节和低饱和紫灰辅助色。大标题、留白、细线证据连接、稳定宽度的时间计数；避免堆砌仪表盘指标。桌面调查说明/轨迹并排，手机纵向排列，长操作列表横向可滚动。减少动态偏好关闭循环动效；状态文字可由辅助技术读取。

## 验收

覆盖未分析、模型未配置、排队、模型等待、工具执行、成功候选、无候选/取消、旧成功与新失败并存、连接断开、未保存修改、只读已发布报告、移动端和减少动态。验证当前真实页面与独立UI夹具，不用合成进度证明真实模型质量。高级分析能力与真实模型质量继续按原工程/评测门槛核验。
