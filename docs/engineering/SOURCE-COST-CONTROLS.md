# 源码分析费用与增量分析交付记录

日期：2026-09-29。适用：普通 ZIP 项目分析，不改写课程执行计费策略。

## 已实现

- 上传和重新分析均提供费用卡。官方 DeepSeek Flash / V4 Pro 按 2026-09-29 高峰、未缓存人民币单价提供保守估算；仅匹配 `https://api.deepseek.com`。自定义供应商可填写输入/输出每百万 token 单价。
- 同账户、同模型/接口、同模式且用量完整的历史成功记录可作为参考，按当前单价重新计算。明确提示项目与范围可能不同，不能视作本次报价。无样本时不编造预计金额。
- 支持 0.5 / 1 / 3 元快捷预算及自定义预算。服务端在每轮调用前，按输入估算、安全余量、最大输出额度检查费用；预算不足以 `SOURCE_COST_BUDGET` 停止，不登记或发出该轮请求。
- 返回已知用量后重新计算；没有用量的已返回请求继续占用预留额度。异常请求不自动重试。终止不退还已经发生的模型费用。
- 本次确认的单价和预算保存在不可变分析选项中。页面区分已知费用估算和待确认预留。历史无价格记录不补造账单。
- 同一源码项目、范围、模型配置和当前报告版本匹配时，可复用已经成功的报告，无新增模型调用。旧报告未经过本次复用版本标记时不会直接纳入缓存。
- 上传新 ZIP 前可选择自己已有的项目作对比版本。按保留、脱敏后的源码逐文件比较新增、修改、删除；不猜测重命名，不复用旧引用与旧判断。
- 变更分析将初始源码阅读字符分配由 60,000 降为 30,000，源码 token 分配系数由 0.4 降为 0.25；优先选取变更文件，并允许搜索关联未改代码，保留反证与引用校验。实际读过的范围仍被记录。报告明确标为变更专项，不等价于全项目复审。

## 设计

费用区采用浅蓝灰底、深蓝灰文字、等宽金额和分段刻度。实色表示已知用量估算，斜纹表示未知用量的预留；不使用虚假的计费完成百分比。保留既有页面主体风格、可见焦点及手机端布局。

## 必须保留的边界

1. 这是应用层费用估算门禁，不是供应商财务硬限额。分词差异、未知用量、供应商调价和自行填写的单价都会影响实付；账户硬限额须在供应商端设置。
2. 为避免峰谷和节假日切换低估，官方默认统一使用高峰、未缓存价；没有声称它是空闲时段实际账单。价格是有日期的快照，不是自动更新的报价服务。
3. 变更分析是较小范围的独立报告，尚未做真实教师质量评测或真实模型 A/B 费用实验，因此不能声称节省固定百分比，也不把未读代码当已审查。
4. 基线必须属于当前用户且仍存在。压缩包应保持目录结构；改根目录会被识别为删除与新增。已脱敏、未导入文件的变化不在比较范围。
5. 达预算上限时保留已有调用记录和事件轨迹，但不发布未经最终复核的草稿；调整预算后是新分析，不承诺从付费中断点续跑。
