- 浏览器：Chrome/Edge/Firefox

## 核心链路 A：普通项目分析

### 验证步骤

#### 1. 未登录保护验证

1. 打开浏览器，访问：`http://127.0.0.1:5173/#/projects`
2. **预期**：自动重定向到 `http://127.0.0.1:5173/#/login?redirect=/projects`
3. **截图保存为**：`test-output/A1-login-redirect.png`

#### 2. 登录流程验证

1. 在登录页面输入：
   - Email: `teacher@example.edu.cn`（或你的测试账号）
   - Password: `password123`（或你的测试密码）
2. 点击"登录"
3. **预期**：
   - 登录成功后重定向到 `/projects`（恢复目标路径）
   - 看到项目列表页面
4. **截图保存为**：`test-output/A2-login-success.png`

#### 3. 项目列表验证

1. 确认在项目列表页面
2. **预期**：
   - 看到"新建项目"或"导入项目"按钮
   - 如果有历史项目，显示项目卡片
   - 顶部导航显示用户信息
3. **截图保存为**：`test-output/A3-projects-list.png`

#### 4. 项目详情验证（如果有历史项目）

1. 点击任意项目卡片
2. **预期**：
   - 进入 `/projects/:id`
   - 看到项目详情页面
   - 显示分析结果或"开始分析"按钮
3. **截图保存为**：`test-output/A4-project-detail.png`

#### 5. 个人模型配置验证

1. 在项目详情页或设置中找到"个人模型配置"
2. 点击打开配置对话框
3. **预期**：
   - 看到模型配置表单
   - 服务商、API 地址、模型名称、API 密钥等字段
4. **截图保存为**：`test-output/A5-model-config.png`

#### 6. 刷新恢复验证

1. 在项目详情页按 F5 刷新
2. **预期**：
   - 页面正确恢复到当前项目
   - 不会退出登录或跳转首页
3. **截图保存为**：`test-output/A6-refresh-recovery.png`

## 核心链路 B：教学任务流程

### 验证步骤

#### 1. 任务列表访问

1. 在导航栏点击"任务"或直接访问：`http://127.0.0.1:5173/#/tasks`
2. **预期**：
   - 看到任务列表页面
   - 教师账号：显示创建任务、管理班级等功能
   - 学生账号：显示可提交的任务
3. **截图保存为**：`test-output/B1-tasks-list.png`

#### 2. 任务详情访问（教师视角）

1. 点击任意任务卡片
2. **预期**：
   - 进入 `/tasks/:id`
   - 教师：看到学生提交列表、规则配置
   - 学生：看到提交表单或已提交状态
3. **截图保存为**：`test-output/B2-task-detail-teacher.png`

#### 3. 学生提交历史（如果有）

1. 在任务详情页查看学生提交
2. **预期**：
   - 显示提交列表
   - 每个提交显示状态（待检查/检查中/已完成）
3. **截图保存为**：`test-output/B3-submissions.png`

#### 4. 运行报告访问（如果有）

1. 点击任意已完成的提交，或直接访问：`http://127.0.0.1:5173/#/runs/:id`
2. **预期**：
   - 看到运行报告页面
   - 显示检查结果、证据、教师复核状态
3. **截图保存为**：`test-output/B4-run-report.png`

#### 5. 教师复核界面（如果有待复核提交）

1. 在报告页面找到"编辑判断"或"开始复核"
2. **预期**：
   - 看到复核表单
   - 可以编辑判断、添加评语
   - 有"保存草稿"和"确认发布"按钮
3. **截图保存为**：`test-output/B5-teacher-review.png`

#### 6. 公开发布查看（如果有已发布报告）

1. 访问已发布报告的公开链接：`http://127.0.0.1:5173/#/publications/:publicationId`
2. **预期**：
   - 学生可以看到已发布的报告
   - 显示最终判断和评语
   - 不显示教师私有草稿
3. **截图保存为**：`test-output/B6-publication.png`

## 已知问题与说明

### 如果没有测试账号

1. **创建测试账号**（如果支持注册）
2. **使用现有账号**（确保是测试环境，不污染生产数据）
3. **联系管理员**获取测试账号

### 如果没有历史项目/任务

以下验证可跳过，但需说明：
- A4（项目详情）- 跳过，无历史项目
- B3-B6（提交/报告/复核/发布）- 跳过，无历史数据

**最低要求**：至少完成 A1-A3 和 B1-B2

### 如果遇到错误

1. **记录错误信息**：
   - 截图保存为 `test-output/error-*.png`
   - 复制控制台错误
   - 记录重现步骤

2. **常见错误处理**：
   - 404 Not Found → 检查路由配置
   - 401 Unauthorized → 检查登录状态
   - 500 Server Error → 检查后端服务
   - CSRF token mismatch → 刷新页面重试
