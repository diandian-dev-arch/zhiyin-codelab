# CodeLab 四组记录协议 v1

本文件作为评测账本引用的固定协议，不是已有教师授权或评测结论。更改协议时另起版本并生成新的账本。

H：正常开发工具与合理缓存，独立人工反馈；R：结构化检查和证据；S：相同封存基础证据的一次模型总结；A：同一基础证据与模型配置的有界 Agent。S 不接受多次模型请求冒充一次性总结；A 的实际调用与补查全部保留。

开始前固定 experimentId、样本登记快照、教师代号、分组、重复次数与比较块。按教师/家族平衡顺序，记录 priorExposure 和 blinded。开发家族不进入验证或冻结分区。计划时间必须早于实际操作，但本地时间声明不等于可信预注册时间戳。

计时从本次工作开始到同等质量反馈发布。分别记录设置、执行等待、阅读、修改、发布；分阶段时间不应重叠，未分类时间仍包含在总耗时内。不把候选返回当终点。完成记录必须附教师修订与发布快照；失败/中止带分类，未开始计划保留 missing，不从分母删除。

S/A 在同一 comparisonBlock、样本及重复编号下，ZIP、规则、环境、基础证据和模型配置哈希必须一致。模型配置文件仅含脱敏 model/version/temperature 等公共参数，不含 key，S/A 的提示与策略作为独立请求记录。请求/响应数量、token、费用、币种、计价依据分别登记；缺失值用 null，不填零。丢失响应仍计入已发请求。

每份材料使用项目内相对路径和真实文件 SHA-256。真实账本、教师评价、授权资料、模型原始请求/响应放在私有 .data 下。公开目录仅保存空模板、协议和脱敏验证说明。只有团队构造样本时，不冒充真实课堂授权或教师评阅。

逐项质量由独立评阅者登记误报、漏报、未执行、事实错误、无依据归因、错误引用、建议可执行性、修订量与再使用意愿，并保留评阅材料。机器只检查结构和文件一致性，不能认证独立性、授权、语义质量或计时真实性。pixelsRead=false 时不可称模型已看截图。

汇总区分 synthetic 与 reviewer-recorded，保留 planned/recorded/missing/completed/failed/aborted，不自动算准确率、节时百分比或模型优越性。任何软件校验成功都不等于 qualityEvaluationCompleted。
